# calculadora.py
calculadora básica en python.Puede hacer ecuaciones básicas ya sea sumar,restar, dividir o multiplicar.Ideal para practicar



#COMO USAR 

Abres el programa y escribes el primer número. Después escribes el segundo número. Después escribes la operación que quieres usar: `+` para sumar, `-` para restar, `*` para multiplicar o `/` para dividir. Te muestra el resultado.

Si quieres ver todo lo que ya calculaste, cuando te pida el primer número escribes `historial` y te muestra todas las cuentas.

Después de cada cuenta te pregunta si quieres seguir. Si escribes `si` sigues calculando, si escribes `no` se cierra.
