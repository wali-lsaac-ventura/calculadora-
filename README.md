# calculadora.py
calculadora básica en python.Puede hacer ecuaciones básicas ya sea sumar,restar, dividir o multiplicar.Ideal para practicar

# COMO USARLA 


1. Abre el programa
2. Escribe un número
3. Escribe el signo: + - * /
4. Escribe otro número
5. Te da el resultado

#EJEMPLO

Si escribes:
- Primer número: 10
- Signo: +
- Segundo número: 5

Te sale:
10 + 5 = 15

#PARA SALIR 

Escribe la palabra: salir

Y listo, se cierra.
